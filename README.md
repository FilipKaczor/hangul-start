# Hangul — koreański krok po kroku

Statyczna aplikacja do nauki hangulu. Otwórz index.html, aby korzystać lokalnie.

## Ćwiczenia

- Quiz alfabetu obejmuje 14 spółgłosek i komplet 21 samogłosek.
- Podstawowy quiz losuje 20 sylab.
- Tryb trudniejszych sylab pozwala budować bloki z końcówką, ćwiczyć słowa i liczby oraz dodawać je do własnego spisu.
- Nowe słowa i liczby są pokazywane ze znaczeniem w spisie. W quizie ćwiczysz samą wymowę.
- Zapis wymowy używa McCune–Reischauera. Dla ㅢ stosuję zapis ŭi, a dla ㅝ — wŏ.

## Publikacja na GitHub Pages

Repozytorium publikuje zawartość katalogu głównego przez GitHub Actions. Po wypchnięciu gałęzi main workflow z pliku .github/workflows/pages.yml uruchomi wdrożenie.

## Dane

Postęp i własne słówka są zapisywane lokalnie w pamięci przeglądarki. Nie są wysyłane na serwer ani synchronizowane między urządzeniami.
