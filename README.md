# Hangul — koreański krok po kroku

Statyczna aplikacja do nauki hangulu. Otwórz `index.html`, aby korzystać lokalnie.

## Publikacja na GitHub Pages

Repozytorium publikuje zawartość katalogu głównego przez GitHub Actions. Po wypchnięciu gałęzi `main` workflow z pliku `.github/workflows/pages.yml` uruchomi wdrożenie. W ustawieniach repozytorium źródłem Pages powinno być **GitHub Actions**.

Po zakończeniu wdrożenia strona będzie dostępna pod adresem `https://<konto>.github.io/<repozytorium>/`.

## Dane

Postęp i własne słówka są zapisywane w pamięci przeglądarki na danym urządzeniu. Nie są wysyłane do serwera ani synchronizowane między urządzeniami.
